# 师范生试讲多模态智能评价 Agent —— 记忆存储结构设计（v1.0）

> 所属阶段：阶段 1｜产出物：记忆存储结构规范
> 编制日期：2026-10-24｜编制人：杨德琰
> 文档定位：定义 Agent 的长期记忆存储结构（跨会话师范生试讲档案），支撑"短板追踪 + 进步对比 + 训练规划"闭环。对应 §3.6 L4 记忆层：短期=LangGraph checkpointer（会话内），长期=SQLite/PostgreSQL（结构化档案）+ 向量库（语义记忆）。
> 配套：《标准化评价指标体系_v1.0.md》（字段口径）、《Agent_SystemPrompt与输出模板_v1.0.md》（输出字段）。

---

## 1. 存储选型

| 存储 | 用途 | 说明 |
|---|---|---|
| SQLite/PostgreSQL | 结构化试讲档案（主存储） | 历次试讲、得分、短板、训练任务、进步对比 |
| 向量库（Chroma/FAISS） | 语义记忆 + RAG 知识检索 | 课标/课例/量表向量；用户历史语义索引 |
| LangGraph checkpointer | 短期会话上下文 | 单次会话内状态恢复、断点续跑（不跨会话） |

> 生产推荐 PostgreSQL（并发、可审计）；内测/单机可用 SQLite 起步。

## 2. 核心数据表设计

### 2.1 用户表 user
| 字段 | 类型 | 说明 |
|---|---|---|
| user_id | TEXT PK | 用户唯一标识 |
| name | TEXT | 姓名（脱敏可选） |
| subject_major | TEXT | 学科专业（汉语言/数学/英语…） |
| grade_level | TEXT | 学段 |
| created_at | TIMESTAMP | 建档时间 |

### 2.2 试讲记录表 trial
| 字段 | 类型 | 说明 |
|---|---|---|
| try_id | TEXT PK | 本次试讲唯一标识 |
| user_id | TEXT FK | 关联用户 |
| subject | TEXT | 课题 |
| lesson_type | TEXT | 课型（新授课/复习课/练习课…） |
| grade_level | TEXT | 学段 |

| video_path | TEXT | 视频文件路径（本地/内测） |

### 2.3 评价结果表 evaluation（每次试讲一条）
| 字段 | 类型 | 说明 |
|---|---|---|
| eval_id | TEXT PK | 评价唯一标识 |
| try_id | TEXT FK | 关联试讲 |
| scores_json | JSON | 四维度 + 二级指标得分（对齐指标体系） |
| overall_percent | REAL | 百分制总评 |
| timeline_feedback | JSON | 分段式细节评语（时间轴） |
| weaknesses | JSON | 短板清单 |
| reflection_log | JSON | Reflexion 自查日志 |
| raw_multimodal | JSON | 多模态原始特征（ASR/姿态/OCR，可追溯） |
| prompt_version | TEXT | 生成所用 Prompt/指标版本（可复现） |

### 2.4 进步对比表 progress（可选，或由 evaluation 派生）
| 字段 | 类型 | 说明 |
|---|---|---|
| user_id | TEXT | 用户 |
| try_id | TEXT | 本次 |
| prev_try_id | TEXT | 上一次 |

| dimension_deltas | JSON | 各维度差值 |

### 2.5 训练规划表 training_plan
| 字段 | 类型 | 说明 |
|---|---|---|
| plan_id | TEXT PK | 规划唯一标识 |

| specific_tasks | JSON | 针对性任务清单 |
| reference_case | TEXT | 对标示范案例 |
| estimated_repeat_times | INT | 建议练习次数 |
| status | TEXT | pending/started/done |

## 3. 记忆访问流程（写入 / 读取）

**写入（评价完成时）：**
1. 落 evaluation（scores + timeline + weaknesses + 多模态特征 + 版本号）；
2. 更新 progress（对比上一次）；
3. 生成 training_plan；
4. 向向量库写入本次语义摘要（供未来检索）。

**读取（新一次评价开始时）：**
1. 按 user_id 读取最近一次 evaluation + progress（判断进步/短板延续）；
2. 向量检索该用户历史相关片段（同课题/同课型）注入 Prompt；
3. 读取课标/量表/课例（RAG 检索）注入 Prompt。

---

## 4. 数据隐私与合规（对应开发前文件 §6）

- 试讲视频、人脸、语音数据**仅用于本地/平台内评价**，不对外分发；
- 原始视频路径仅存于内测环境；评价结果库可脱敏保留用于测试指标；
- 内测文档中说明隐私保护方案（同意书、数据范围、留存期限）。
