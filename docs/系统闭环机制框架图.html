⑥ 两条回流闭环（专家复评提交后 旁路触发，绝不阻断主流程）
环 1
🧠 知识闭环 —— 争议课例脱敏回流入向量库（recycle.py）
触发门槛：总分差 ≥ 8 分 或 任一维度差 ≥ 2 分，且教师写了校正意见
处理：去掉学生姓名/学号/user_id → 拼成"争议课例文本" → BGE 编码 → 以 doc_type=case、subject=该课学科 加入同一个 Chroma collection
幂等：同一 try_id 只回流一次（按元数据 try_id 去重）
效果：下次同学科学生上传类似课题，RAG 就能召回"人机分歧边界案例"，让 LLM 打分更贴近该教师口径
回到 ③ RAG 检索 同学科再召回时
自动带上这条
"机器曾在此失手"
的边界案例
环 2
📏 数值闭环 —— 机器分 vs 专家分偏差校准（calibration offset）
样本门槛：累积 ≥ 5 条 expert_review 才启用（样本不足不校准）
计算：对每条复评取 (专家分 − 机器分)，按 overall / D1 / D2 / D3 / D4 分别求均值 offset
方向：正值 = 机器一贯偏严需上调；负值 = 机器一贯偏松需下调
使用：get_calibrated_score() 在展示最终分时给 raw 分加 offset，并标注"基于 N 份专家复评校准"
回到 ⑤ evaluate 分数 后续机器分
自动加偏移量
逐步逼近教师口径
（带样本量标注）
